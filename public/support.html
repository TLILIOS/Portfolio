Support

Cette page centralise le support des applications éditées par Prim (TLILI HAMDI) sur l'App Store, ainsi que les demandes liées à ce site.

Contact support : support@primapp.dev

Réponse sous 48 h ouvrées. Merci d'indiquer le nom de l'application, sa version (Réglages de l'app ou fiche App Store) et la version d'iOS.

Signaler un bug

Décrivez les étapes pour reproduire le problème, le comportement attendu et le comportement observé. Une capture d'écran ou un enregistrement aide beaucoup.

Demander une fonctionnalité

Les suggestions sont les bienvenues — décrivez le besoin et le contexte d'usage plutôt que la solution.

Confidentialité des applications

Les applications Prim privilégient le traitement local des données. Le détail des données traitées par chaque application figure sur sa fiche App Store et dans la politique de confidentialité.
